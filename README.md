# Animal Emotion and Behaviour Detection

AI-based system for detecting animal emotions and behaviour using audio and video.

## Features
- Detects animal emotions
- Behaviour analysis
- Audio processing
- Video analysis
- Flutter mobile app

## Technologies Used
- Python
- Flutter
- Machine Learning
- OpenCV

## Project Structure
- AI model
- Dataset
- Flutter App

## Future Improvements
- Real-time detection
- Cloud integration
- Better emotion accuracy
