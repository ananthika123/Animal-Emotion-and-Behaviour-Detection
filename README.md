# Animal Emotion and Behaviour Detection

AI-based system for detecting animal emotions and behaviour using audio and video.

## Features

- Detects animal emotions
- Behaviour analysis
- Audio processing
- Video analysis
- Flutter mobile application

## Technologies Used

- Python
- Flutter
- Machine Learning
- OpenCV

## Project Structure

- AI model
- Dataset
- Flutter App
- Screenshots

## Future Improvements

- Real-time detection
- Cloud integration
- Better emotion accuracy
